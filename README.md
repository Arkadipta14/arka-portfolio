# 🤖 Arkadipta’s AI Portfolio

A personal portfolio built with **React + Vite** showcasing my AI Engineering journey — projects, skills, and certifications.

## 🧠 Tech Stack for this postfolio
- React 18 + Vite
- Framer Motion (animations)
- React Router DOM
- GitHub Pages deployment (via gh-pages)

## 🚀 Commands
```bash
npm install
npm run dev       # local dev
npm run build     # build for production
npm run deploy    # deploy to GitHub Pages
